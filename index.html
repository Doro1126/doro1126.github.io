현상

인증번호 요청 API는 즉시 성공 응답, 실제 메일은 최대 12~16분 뒤 도착

원인 분석

알림 서비스 로그에서 DB 저장 실패 반복 확인

코드에 있는 컬럼이 QA DB 스키마에 미반영되어 저장 쿼리 실패

저장에 실패한 메시지가 큐에서 30초마다 재전달되며 재시도 반복

조치

누락 컬럼 추가 후 재시도 없이 0.2초 발송 확인

다른 데이터를 지운 상태에서도 즉시 처리되는지 확인해 유일한 원인으로 확정

재발 방지
