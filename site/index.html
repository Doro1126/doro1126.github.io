# about

DevOps 경력 1년 9개월. 클라우드 엔지니어 교육과정을 거쳐 하이브리드 인프라 운영(그루핀)과 레거시 인프라의 신규 플랫폼 전환(집닥)을 맡아 왔습니다.

"제가 직접 처리하는 일"보다 "다음 사람이 같은 판단을 반복하지 않게 하는 일"에 시간을 씁니다. 배포는 파일 두 개로 끝나게, 알림은 같은 방식으로 바로 추가할 수 있게, 인프라 소유 경계는 한 문장 기준으로 정리하는 식입니다.

AI 도구(Kiro, MCP)를 인프라·로그·비용 분석에 활용하되, 결과는 공식 문서와 실행 결과로 검증한 뒤 적용합니다.
